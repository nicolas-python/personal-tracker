flask elemente:

request = Zugriff auf die vom Browser gesendeten Daten
request.form = Zugriff auf Daten aus einem HTML-Formular
flash = Nachricht für die nächste Seite speichern
redirect = Browser zu einer anderen Route schicken
session = merkt sich welcher Benutzer gerade eingeloggt ist


Datenbank:
Passwort-Hashing = Passwort wird einseitig in einen Hash umgewandelt und nicht als Klartext gespeichert.
                   Dadurch kann das ursprüngliche Passwort aus dem Hash nicht einfach zurückgerechnet werden.
                   Beim Login wird das eingegebene Passwort mit dem gespeicherten Hash geprüft.

HTML :
class = Kennzeichnet HTML-Elemente für CSS/JavaScript
id = Eindeutiger Name eines HTML-Elements
loop.index = aktuelle Nummer im Durchlauf
setsInput.type = "number" ist der HTML-Eingabetyp und erlaubt Zahleneingaben
step = "0.5" = bestimmt die Schrittweite bei einer Zahleneingabe

{% if ... %} = Jinja2-Syntax =  Mit Jinja kan man innerhalb der HTML-Datei Python-ähnliche Logik benutzen
{% for ... %} = Wiederhole etwas für mehrere Werte

rel="stylesheet" = Diese verlinkte Datei ist ein Stylesheet, eine CSS-Datei die das Aussehen dieser HTML-Seite bestimmt.


CSS :
padding = Abstand zwischen Inhalt und Rand eines Elements (innen)
margin = Abstand außerhalb eines Elements
display: flex = Macht ein Element zu einem Flex-Container und ermöglicht flexible Anordnung der Inhalte
justify-content = Anordnung der Elemente auf der Hauptachse z. B. flex-start = links, center = Mitte, flex-end = rechts
align-items = Anordnung der Elemente auf der anderen Achse z. B. center = mittig
flex-direction = Bestimmt die Richtung der Hauptachse  z.b row = waagerecht, column = senkrecht
gap = Abstand zwischen mehreren Elementen innerhalb eines Containers
border = Erstellt einen Rand um ein Element
border-radius = Macht Ecken eines Elements rund
