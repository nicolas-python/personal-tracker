Datenbank:
Passwort-Hashing = Passwort wird einseitig in einen Hash umgewandelt und nicht als Klartext gespeichert.
                   Dadurch kann das ursprüngliche Passwort aus dem Hash nicht einfach zurückgerechnet werden.
                   Beim Login wird das eingegebene Passwort mit dem gespeicherten Hash geprüft.

DISPLAY :
display: flex = Macht ein Element zu einem Flex-Container und ermöglicht flexible Anordnung der Inhalte
display: grid = Macht ein Element zu einem Grid-Container und ermöglicht Anordnung in Zeilen und Spalten

display: inline-block = Element bleibt in der Zeile, kann aber Breite und Höhe besitzen
display: none = Element wird nicht angezeigt

Raspberry:
Tailscale = separat auf Raspberry installiert = eigenes Systemprogramm für sicheren Netzwerkzugriff -> ermöglicht Zugriff auf die Website über andere Netzwerke
sudo systemctl restart personal-tracker = startet die Flask-Anwendung neu und lädt den neuen Code
sudo systemctl status personal-tracker = zeigt, ob die Flask-Anwendung erfolgreich läuft

Funnel beenden:
sudo tailscale funnel --https=443 off = beendet den öffentlichen Zugriff auf die Website

Funnel starten:
sudo tailscale funnel --bg 5001 = Starten (bg = background)

Funnel Prüfen
sudo tailscale funnel status = Prüfen

Flask-Autostart beenden:
sudo systemctl disable --now personal-tracker = stoppt Flask und deaktiviert den automatischen Start

Flask-Autostart
sudo systemctl enable --now personal-tracker

Flask-Autostart Prüfen
sudo systemctl status personal-tracker = Prüfen
