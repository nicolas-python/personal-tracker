# QA-Testplan – Personal Tracker

## Testbereiche

## 1. Login
- [ ] Login mit korrekten Zugangsdaten
- [ ] Login mit falschem Passwort
- [ ] Login mit unbekanntem Benutzernamen
- [ ] Login ohne Eingabe
- [ ] Login-Button testen
- [ ] Passwort anzeigen/verbergen testen
- [ ] Mehrfach falsche Loginversuche testen
- [ ] Login mit Enter Taste

## 2. Registrierung
- [ ] Registrierung mit gültigen Daten
- [ ] Registrierung mit bereits vorhandenem Benutzernamen
- [ ] Registrierung mit leerem Passwort
- [ ] Passwortanforderungen testen

## 3. Trainingspläne
- [ ] Trainingsplan erstellen
- [ ] Trainingsplan bearbeiten
- [ ] Trainingsplan löschen
- [ ] Übungen hinzufügen und entfernen
- [ ] Training starten und abschließen

## 4. Ernährung
- [ ] Lebensmittel suchen
- [ ] Lebensmittel hinzufügen
- [ ] Lebensmittel löschen
- [ ] Mahlzeiten speichern
- [ ] Vergangene Tage aufrufen

## 5. Rezepte
- [ ] Rezepte suchen
- [ ] Rezeptdetails öffnen
- [ ] Zutaten und Zubereitung anzeigen

## 6. Tanken
- [ ] Suche mit gültiger PLZ
- [ ] Suche mit ungültiger PLZ
- [ ] Kraftstoffarten wechseln
- [ ] Nach Preis sortieren
- [ ] Nach Entfernung sortieren
